# ================================================================
#  分类覆盖表    （可选文件，删掉也不影响运行）
# ================================================================
#  为什么要它：自动分类是按图标颜色算出来的，不一定符合你的审美。
#  在这里写几行规则，就能强制指定某个图标归到哪一类，
#  而且以后每次双击「桌面图标工具.cmd」都会照着你的规则执行。
#
#  格式：    图标名 = 取值             （等号两边空格随意）
#
#  取值可以是两种：
#     · 颜色系：WHITE  RED  ORANGE  YELLOW  GREEN  CYAN  BLUE  PURPLE  BLACK
#     · 区域　：FILE（临时文件） FOLDER（文件夹） APP（应用软件）
#               SPECIAL（此电脑 / 回收站）
#
#  图标名 = 桌面上显示的名字（快捷方式不用写 .lnk）
#  以 # 开头的行是注释，空行会被忽略。
#  改完保存即可，下次排列生效，不用重装任何东西。
#  写错的名字或不认识的取值会被忽略，并在运行时打印一行提示。
# ================================================================
#
# --------- 下面是例子，把行首的 # 去掉就生效 ---------
#
# 汽水音乐 = GREEN            # 比起黑色系，我更想把它归到绿色
# 微信 = WHITE                # 挪到最上面的白色系
# 完美世界竞技平台 = ORANGE   # 从黄色改成橙色
# Projects = APP              # 这个文件夹快捷方式按应用软件处理
# 咖啡烘焙机 = APP            # 反过来，把真文件夹也当应用软件
#
