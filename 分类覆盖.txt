# ================================================================
#  分类覆盖表    （可选文件，删掉也不影响运行）
# ================================================================
#  为什么要它：自动分类是按图标颜色算出来的，不一定符合你的审美。
#  在这里写几行规则，就能强制指定某个图标归到哪一类，
#  而且以后每次双击「1-排列桌面.cmd」都会照着你的规则执行。
#
#  格式：    图标名 = 取值             （等号两边空格随意）
#
#  取值可以是两种：
#     · 颜色系：WHITE  RED  ORANGE  YELLOW  GREEN  CYAN  BLUE  PURPLE  MIXED  BLACK
#               （MIXED = 杂色，专收"怎么分都不对"的图标）
#     · 区域　：FILE（临时文件） FOLDER（文件夹） APP（应用软件）
#               SPECIAL（此电脑 / 回收站）
#
#  图标名 = 桌面上显示的名字（快捷方式不用写 .lnk）
#  以 # 开头的行是注释，空行会被忽略。
#  改完保存即可，下次排列生效，不用重装任何东西。
#  写错的名字或不认识的取值会被忽略，并在运行时打印一行提示。
# ================================================================
#
# --------- 下面是例子，把行首的 # 去掉就生效 ---------
#
# 微信 = GREEN               # 把一个偏黑的图标改判成绿色系
# 记事本 = WHITE             # 指定进最上面的白色系
# 某个文件夹 = APP           # 让文件夹也进应用区参与颜色排列
# 某个文件 = FOLDER          # 反过来，把文件当文件夹处理
# SomeApp = ORANGE           # 英文名同样支持
#
